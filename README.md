# WSB Merito

## Co tu znajdziesz?

Na tej stronie znajdą Państwo materiały i notatki do prowadzonych przeze mnie zajęć. Staram się, żeby były one przystępne, praktyczne i — na ile to możliwe — nie usypiały na stojąco.

Materiały będą sukcesywnie uzupełniane w trakcie semestru, więc warto tu zaglądać regularnie.

Notatki: https://kubzal.github.io/wsb-merito
